# OpenFrame NDB 추가 지침

## 적용 범위
`$SOURCE_BASE/ndb/**`에 적용한다. 환경·Git·증거·보고와 여러 제품의 지침 적용은 루트 `AGENTS.md`를 따른다.

## 담당 기능과 매뉴얼
NDB는 Fujitsu AIM DB와 Hitachi XDM/SD DB에 대응한다.

- 매뉴얼: `{{manual_base}}/openframe_ndb`

## 변경과 검증
- Jira의 스키마·SQL·데이터·오류 정보는 현재 정의, 실제 데이터 접근 경로와 DB 로그에서 검증한다.
- 스키마·SQL·인덱스·접근 로직 변경 전에 조회·저장 흐름, 기존 데이터 호환성과 영향 범위를 확인한다.
- 실제 조회·저장 또는 동등한 재현 절차로 데이터 정합성과 예외 시 부분 반영·불완전 상태 여부를 검증한다.
- 성능 영향이 있는 변경은 쿼리 수·반복 접근을 점검하고 가능하면 같은 조건의 전후 결과로 비교한다.
- 오류가 발생하면 OpenFrame 로그와 SQL 오류 메시지를 함께 확인한다.
